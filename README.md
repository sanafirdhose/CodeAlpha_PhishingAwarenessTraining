# Phishing Awareness Training

**CodeAlpha Cyber Security Internship – Task 2**

## Project Overview
This project aims to educate individuals about phishing attacks, common cyber threats, and safe online practices.

## Objectives
- Understand phishing and its different types.
- Identify suspicious emails and fraudulent websites.
- Recognize social engineering techniques.
- Learn effective phishing prevention strategies.
- Improve cybersecurity awareness through interactive quizzes.

## Topics Covered
1. Introduction to Phishing
2. How Phishing Attacks Work
3. Types of Phishing
4. Identifying Phishing Emails
5. Recognizing Fake Websites
6. Social Engineering Techniques
7. Realistic Phishing Scenarios
8. Phishing Prevention Strategies
9. Responding to Phishing Attempts
10. Interactive Awareness Quiz

## Tools Used
- Canva
- GitHub

## Project Deliverables
- 12-slide Phishing Awareness Training presentation
- Educational phishing examples
- Interactive knowledge quiz
